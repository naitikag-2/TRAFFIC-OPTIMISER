Mathematical Baseline: Webster's Optimum Cycle Formula

C₀ = (1.5 · L + 5) / (1 - Y)

Where C₀ is the optimal cycle length, L is the total lost time per cycle (12s), and Y is the sum of directional saturation flow ratios (yNS + yEW). The Reinforcement Learning Q-agent fine-tunes green-split ratios in real-time to eliminate queue spikes.

Test Setup

Simulated 4-way intersection with CCTV camera coverage at 30fps, 1080p resolution. Camera positioned overhead at 8m height covering all 4 approach lanes. N=4 intersections tested across 3 Indian urban road geometries.

Dataset Size & Duration

14 hours of simulated traffic across 6 density scenarios (Low / Medium / High / Surge / Incident / Mixed). Approximately ~2.4M vehicle detection frames processed via YOLOv8n. Seed set to ensure reproducibility across Fixed vs Adaptive runs.

Comparison Baseline

Fixed-Time controller benchmarked using a rigid 30s green + 3s yellow symmetric cycle (standard IRC:93-1985 specification). No adaptive logic, no sensor feedback. All percentage improvements are relative to this baseline.

Hardware & Inference

AI inference benchmarked on Google Coral Edge TPU (4 TOPS) running YOLOv8n INT8-quantized model. Average inference latency: 1.4ms/frame. Signal command dispatch over MQTT at <120ms end-to-end.

Pipeline Architecture

End-to-End System Architecture

Sub-second pipeline from edge CCTV video frames to physical signal hardware commands

CCTV / Sensors RTSP 1080p Feed

Extracts raw video frames from intersection cameras at 30fps. The feed is transcoded and downsampled at the edge to optimize memory bandwidth before being pushed to the vision pipeline.

Edge AI YOLOv8 + OpenCV

A quantized YOLOv8 model runs on an edge TPU/NPU, detecting vehicles, pedestrians, and cyclists in real-time. OpenCV is used for bounding box tracking and trajectory estimation.

Density Matrix Approach Saturation (Y)

Outputs from the Edge AI are mapped into a spatial matrix. We calculate the approach saturation (Y) by measuring queue lengths, vehicle density, and flow rate for each incoming lane.

Timing Optimizer Webster + RL Q-Agent

A hybrid engine uses Webster's formula for baseline cycle length, while a Reinforcement Learning (RL) Q-Agent fine-tunes green splits dynamically to minimize overall intersection delay.

Controller API REST + MQTT Relay

The optimized timing decisions are serialized into JSON commands and securely transmitted to the traffic cabinet via a low-latency REST API or MQTT publish-subscribe relay.

Signal Hardware Relay / SCATS/SCOOT

Physical relays or SCATS/SCOOT interfaces intercept the digital commands and trigger the phase changes on the actual traffic lights, completing the autonomous loop.
